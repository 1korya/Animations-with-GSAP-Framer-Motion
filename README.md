# project-tanstack-router

Многостраничное приложение на React + MUI с навигацией через **TanStack Router v1**.

## Установка и запуск
```bash
# 1. Установить зависимости
npm install

# 2. Запустить проект
npm run dev
```

Открыть в браузере: http://localhost:5173

## Стек

- React 18
- Vite
- Material UI (MUI)
- @tanstack/react-router v1
