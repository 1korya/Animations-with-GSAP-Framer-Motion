Многостраничное приложение на React + MUI с навигацией через **TanStack Router v1**.
# Анимации с Framer Motion

Проект для изучения и демонстрации возможностей библиотеки **Framer Motion** в React-приложении. Реализованы различные типы анимаций: появление списков, hover-эффекты, exit-анимации при размонтировании компонентов и интерактивная обратная связь на tap.

# Демонстрация анимаций

| Тип анимации | Где используется |
|--------------|------------------|
| **Stagger** (каскадное появление) | Карточки на страницах Home, About, Contacts; строки заказов в Profile |
| **Появление снизу/сбоку** (fade + slide) | Все заголовки страниц, поля форм |
| **Hover подъём карточки** | Товары на Products, карточки команды на About, контакты на Contacts |
| **Hover + Tap кнопок** | Все кнопки на всех страницах |
| **AnimatePresence (exit-анимация)** | Фильтрация товаров, Alert в Contacts, переключение режима редактирования в Profile |
| **Hover аватара (вращение)** | Аватар на странице Profile |

# Установка и запуск

```bash
# 1. Установить зависимости
npm install

# 2. Запустить проект
npm run dev
```

Открыть в браузере: http://localhost:5173

# Структура анимаций
1. Stagger-анимация для списков

2. Появление снизу/сбоку (fade + slide)

3. Hover + Tap для интерактивных элементов

4. AnimatePresence для exit-анимаций

5. Вращение аватара при hover

# Как проверить

| Тип анимации                | Где используется                                                                              | Как проверить                                                              |
|-----------------------------|-----------------------------------------------------------------------------------------------|----------------------------------------------------------------------------|
| **Stagger**                 | Карточки на Home, About, Contacts, Profile (строки заказов)                                   | Перейти на любую страницу — карточки/строки появятся каскадно              |
| **Slide + Fade**            | Все заголовки страниц, поля форм                                                              | Заголовки и поля будут выезжать снизу при загрузке страницы                |
| **Hover подъём**            | Карточки товаров (Products), участники команды (About), контакты (Contacts)                   | Навести курсор на карточку товара, участника команды или контакт           |
| **Hover + Tap кнопок**      | Все кнопки на всех страницах (отправить, фильтр, редактировать, и т.д.)                       | Нажать или навести на любую кнопку                                         |
| **Exit-анимация**           | Фильтрация товаров (Products), Alert в Contacts, переключение режима редактирования (Profile) | Отфильтровать товары → исчезновение элементов; в Contacts — закрыть Alert; в Profile — выключить режим редактирования|
| **Вращение аватара**        | Аватар пользователя (Profile)                                                                 | Навести курсор на аватар в Profile                                            |
